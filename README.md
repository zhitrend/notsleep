## 🌟 NotSleep Project

NotSleep is an innovative solution designed to prevent your computer from entering sleep mode while maintaining system activity. It's perfect for users who need to keep their systems active during long-running tasks, downloads, or remote access sessions.

### ✨ Features

- **Prevent Sleep Mode**: Keeps your computer awake and active
- **Customizable Settings**: Configure how the system should behave
- **Resource Efficient**: Minimal impact on system performance
- **Easy to Use**: Simple and intuitive interface
- **Cross-Platform**: Works on multiple operating systems

### 🚀 Getting Started

#### Prerequisites

- Node.js (version 12.0 or higher)
- npm (comes with Node.js)

#### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/notsleep.git
```

2. Navigate to the project directory:
```bash
cd notsleep
```

3. Install dependencies:
```bash
npm install
```

4. Start the application:
```bash
npm start
```

### 🔧 Configuration

The application can be configured through the `config.json` file:

```json
{
  "interval": 60,
  "notification": true,
  "logLevel": "info"
}
```

- `interval`: Time between actions (in seconds)
- `notification`: Enable/disable system notifications
- `logLevel`: Logging level (debug, info, warn, error)
